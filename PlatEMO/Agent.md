## 双种群与真实评价

1. 初始化约束种群 P1 与忽略约束的辅助种群 P2，各 N 个体；不足预算时按实际剩余数初始化。
2. 每代开始时，先使用当前 P1/P2、存档和资源状态判断 CGAN 是否仍 active，并在需要时首训/续训或复用已有模型，生成本代 q。末代按剩余 FE 分配，绝不超预算。
3. 随后 P1/P2 各生成 N 个子代，均为 `round(.25*N)` 个 GA，其余 DE。P1 立即消费本代 q 引导最后 m 个 DE 槽；按 q 与真实父代的归一化距离贪心一一匹配；桥接、原 DE 交叉/修复/变异之后，再按 q 最近的真实 F/I 线段作局部收缩。P2 只使用普通 GA/DE。
4. 只评价最终搜索子代；q、线段、中心和反事实 DE 均不免费真实评价，也不直接进入种群。恰与 q 重合时保留普通 DE 回退及直接评价保护。
5. P1 从 `[P1,O1,O2]` 作约束环境选择；P2 从 `[P2,O1,O2]` 作无约束环境选择。存档重建接收选择前完整 `[P1,P2,O1,O2]`。

## 真实端点存档

- 最多 500 对真实可行 F / 不可行 I 端点，每方向至多一个 active 对，其余为候选备份；不强行补满、不按年龄淘汰。
- 历史对先接受实际引导子代收紧，再接受普通评价点与历史端点收紧。保留顺序和五参考方向邻域。
- F 来自完整可行池的第一非支配前沿；I 不得被该前沿支配。先筛资格，再在邻域中找最近合法异侧端点，不能让不合法近邻遮蔽合法远邻。
- 端点、方向、间隙、稳定 ID 和 active 标志属于运行状态；研究日志、反事实影子存档和统计诊断不属于搜索状态。

## 唯一资源控制

每代开始时把当前 P1/P2 按决策去重。U 为忽略约束的第一非支配前沿，F 为可行第一非支配前沿；交并集按真实个体身份计算：

`S = 1 - |U ∩ F| / |U ∪ F|`

`C = min(U覆盖方向数, F覆盖方向数) / |W|`

初始 `z=20`；C=0 或信号无效时保持 z，否则：

`z ← (1 - 0.04*C)*z + 0.04*C*(10 + 20*S)`

`Q = clip(round(z), 10, 30)`

`tau = clip(0.2 + 0.5*(z-10)/20, 0.2, 0.7)`

`cutoffFE = floor(tau*maxFE/(2N) + 1e-10) * (2N)`

在每代子代生成之前，当 `当前FE + 2N > cutoffFE` 时永久停止 CGAN；之后不训练、不生成、不消费，也不再计算已无搜索用途的存档和控制信号。普通双种群继续到预算耗尽。初始名额为 20，映射出的初始 tau 是 **0.45**。

数学上可令 `r=(z-10)/20`，写成 `r←r+0.04*C*(S-r)`、`Q=round(10+20r)`、`tau=.2+.5r`；运行代码保留 z 的原运算顺序，避免浮点变化。没有额外固定步幅；状态每代变化绝对值不超过 .8，取整后的名义 Q 每代最多变 1。实际引导数还受模型、筛选供给和停止门控影响。

## 条件训练、生成与筛选

| 项目 | 固定主线设置 |
| --- | --- |
| 网络 | 潜变量 12；G 两层 `[8,8]`；critic 两层 `[16,16]`；条件为原始参考向量 w 与真实侧别 s∈{0,1} |
| 训练 | WGAN-GP；GP=10；Adam 学习率均 .001、β=(0,.9)；critic:G=5:1 |
| 预算 | 首训 1000 次 G 更新，续训 20 次；batch 上限 64、偶数；训练/查询噪声 σ=.1 |
| 训练门槛 | 至少 8 个 active 对；数据变化≥.2 或距上次训练≥10代时续训；已有模型可在不足8对、仍有至少1对时查询 |
| 数据 | active 对的两侧端点，按 `[x,s]` 去重；侧别各半、方向均衡；无错配负例或端点回归损失 |
| 查询 | 每代子代生成前 500 个，覆盖完整参考方向，侧别各 250；不评价这些生成点 |
| 筛选 | 全部存档端点的决策包围盒；盒内按到最近真实 F 的距离及原行号排序 |
| 探索 | 仅未覆盖且盒外的请求方向，每方向最多1点，总计最多 `floor(.2*Q)`；不足退回盒内，总量不足由 DE 补齐 |

“未覆盖”按 P1 全部点及存档全部端点在当前参考尺度下判断；请求侧别、请求方向均不是生成点真实标签。五分之一是盒外探索的计划上限，不能写成所有未覆盖方向始终精确占20%。固定设计常数与数值容差须披露，不能称整个算法无参数。

MATLAB 随机流、采样形状、浮点精度、并列排序、网络初始化/更新顺序必须保持。原研究诊断通过 `rng` 恢复状态时复制训练流；精简版显式保留这项既有行为，不因删除诊断改变续训随机序列。梯度及权重非有限时回退旧模型，合法性和预算保护不可为缩短代码删除。
