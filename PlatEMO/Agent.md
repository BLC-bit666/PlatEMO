# GANCMO 工作约定

## 唯一主线

- 入口：`Algorithms/Multi-objective optimization/GANCMO/GANCMO.m`；固定参数仅在 `GANCMOSettings.m` 定义。只保留一套生产实现，无版本开关或外部参数覆盖。
- 用户已确认 **8/8**：首训、续训共用 `minimumDirections=8`，统计当前Z下有合法存档对的不同F方向。续训还需存档变化≥0.2或距上次训练≥20代；方向不足仅跳过训练，已有模型继续生成。
- 固定G128/Critic16、初训6000/续训1000个G更新、Critic:G=2:1。保持联合输入 `[D维噪声; M维单位方向; 真实侧0/1]`、sin/LeakyReLU(0.2)、WGAN-GP、100倍最近端点RMS损失、Adam与原学习率衰减。
- P1/P2各N，每代合计N次真实评价并截断尾部预算。P1的G比例随FE由0.1升至0.9，不足补DE；P2仅DE。G直接评价、只进入P1选择。训练、查询、DE随机流独立。
- W固定；Z累计全部真实评价的逐目标历史最小值，包括不可行和淘汰解。目标仅作 `f-Z` 平移；代内训练/查询共用代初Z，评价后更新Z并统一重配全部新旧端点。
- F属合并可行池非支配前沿，I不被该前沿支配；每个F在五方向邻域找最近合法I。按F质量、目标间距、归一化决策间距、决策字典序确定保留顺序；每方向最多5对、首对指导候选、全部对训练。无P1归属筛选、旧代表优先或空位转移。
- 均匀查询全部W共500候选。有代表方向在共同端点盒内按距本方向F排序，无代表方向按同请求条件的Critic分数排序；每方向至多1个，共享G配额。保留边界、有限值、去重、DE补足及训练失败回退。
- 完整公式、固定数值与调用流程见算法目录 `README.md`；未经新授权不改变上述机制。
