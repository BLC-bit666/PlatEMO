# GANCMO 工作约定

## 唯一主线

- 入口为 `Algorithms/Multi-objective optimization/GANCMO/GANCMO.m`，固定参数只在 `GANCMOSettings.m` 定义；不保留可运行旧版本、探索开关或参数覆盖入口。
- 网络固定 G=128、Critic=16，初训/续训 G 更新6000/1000次，Critic:G=2:1。G 使用 `[D维噪声; M维单位参考向量; 真实侧0/1]`，sin隐藏层、线性输出；Critic 使用 LeakyReLU(0.2)、无界标量输出。噪声σ=0.02，参考输入权重初始化尺度256。
- P1/P2各N；每代合计N次真实评价，预算尾部截断。P1的G计划比例随FE由0.1升至0.9，不足补DE；P2仅DE。G子代直接评价且仅进入P1选择，保留独立训练、查询和DE随机流。
- W仅初始化一次，不改变N。Z累计全部真实评价的逐目标历史最小值，包含不可行、被淘汰解；目标仅平移 `f-Z`。每代评价后更新Z，重新分配端点方向并复查旧对邻域。
- 合并新旧端点配对：F属于合并可行池非支配前沿，I不被该前沿支配，邻域5方向、容量500。仅存 `ref/xf/yf/xi/yi`，全部存档训练；每方向按F质量、目标间距、同优留旧选一个候选指导代表。
- 首训至少8对、续训至少2对；全部存档变化阈值0.2或间隔20代触发。保留WGAN-GP、100倍同方向同真实侧最近端点RMS损失、Adam及原学习率衰减。上次训练数据与条件不随Z改写，不重置模型。
- 均匀查询全部W共500候选。有代表方向在全部代表端点共同盒内按距本方向F排序；无代表方向按条件Critic分数降序，无分数阈值。每方向至多1个，共享G配额，保留边界、有限值、去重与DE补足。
