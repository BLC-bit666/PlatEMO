# PRBCCMO-v2 算法思想和创新点

## 1. 文档口径

本文记录的是建议版 `PRBCCMO-v2` 的算法思想，不等同于当前源码已经完成的实现。

当前源码仍保持以下状态：

* `QC = [PopulationC, OffspringC, OffspringU]`；
* helper refinement 只用 active B pair 的决策中点替换部分 `OffspringUDec`；
* `B` 的更新仍由 `BuildTargetBoundaryArchive + BlendBoundaryArchive` 完成，且统一受 `etaB=0.2` 限制；
* `EnvironmentalSelectionC_ObjectBoundary` 在 `Feasible >= N` 时直接返回，不触发不可行选择分支；
* model-ready 后不可行候选仍受 sector round-robin 包装，MLP 概率排序没有完全作用到最终不可行位点。

`PRBCCMO-v2` 的目标是在不增加复杂分支、不引入额外损失、不强化双群体耦合的前提下，闭合以下因果链：

`B 严格收缩成可行/不可行 bracket`
-> `T = B + recent refinement + small real boundary-band 提供短期真实训练视野`
-> `MLP 学习边界附近的可行概率先验`
-> `infeasible carry 位被 objective relevance + MLP probability + boundary geometry 统一排序`

## 2. 算法定位

PRBCCMO 面向二元未知约束多目标优化，采用三份点集协同搜索：

* `PopulationC`：主群体，负责逼近受约束 Pareto 前沿；
* `PopulationU`：辅助群体，负责保持目标搜索能力与跨不可行区探索能力；
* `B`：严格边界括号存档，负责维护当前阶段的 feasible / infeasible endpoint pairs，并作为 MLP 训练缓冲区 `T` 的核心锚点。

算法主线为：

1. `PopulationC` 与 `PopulationU` 按 CCMO 式弱合作并行搜索；
2. `B` 在目标空间维护 feasible / infeasible boundary pairs；
3. helper offspring 用少量 B pair 决策中点产生边界精炼样本；
4. 评估后的精炼样本按 bracket 是否变紧决定是否回写同一 pair；
5. 用固定长度训练缓冲区 `T` 周期性训练轻量 MLP，其中 `B endpoints` 永远保留，recent refinement 优先，少量 real boundary-band 只做补充；
6. model-ready 后，`PopulationC` 保留极小不可行 carry 位，并用 objective relevance、MLP 概率和 boundary geometry 的统一 key 恢复不可行选择压力。

## 3. 目标空间边界定义

本文中的 `B` 只表达一件事：

```text
(x_f, x_i), x_f feasible, x_i infeasible
```

这对端点之间夹着真实未知约束边界。`B` 的局部目标是让 bracket 更紧，而不是让 pair 中点更靠近当前可行前沿。

因此：

* 扇区划分在目标空间进行；
* pair 的构造在目标空间进行；
* `FrontGap` 只作为 objective-side relevance，不再作为局部边界贴合指标；
* 候选解与 `B` 的支持距离可作为 infeasible 选择的几何稳定器；
* same-pair contraction 的接受准则优先看 decision-space bracket 是否变紧。

决策空间只承担两个辅助角色：

1. MLP 的输入仍为决策变量，用来学习 `p(feasible | x)`；
2. helper refinement 用 pair 两端的决策中点生成待评估样本，并用真实标签更新 bracket。

决策中点只是采样方式，不是新的边界定义；但在同一 pair 的局部收缩中，`decGap` 是 bracket 是否变紧的第一证据。

## 4. B 的基本结构

设参考向量数为 `K = |W| = N`。边界存档 `B` 的基本单位是 pair，不是单点。

每个 pair 由一对目标空间邻近的异标签样本组成：

* `x_f`：可行端点；
* `x_i`：不可行端点。

总 pair 预算为：

```text
N_B = ceil(betaB * N)
```

默认：

```text
betaB = 1.5
```

因此默认 `B` 大约包含 `2 * N_B = 3N` 个点。这个规模使 `B` 既能覆盖多个目标空间扇区，又能在复杂边界区域保留多对 pair。

## 5. 目标空间 pair key

### 5.1 目标归一化

每代在当前候选池上做目标归一化：

```text
f_norm = (f - z_ideal) / (z_nadir - z_ideal + eps)
```

后续 objective relevance、扇区关联和全局候选排序都基于归一化目标。

### 5.2 pairGap

对 feasible-infeasible pair：

```text
pairGap = ||f_norm(x_f) - f_norm(x_i)||_2
```

`pairGap` 越小，表示这对端点在目标空间中越接近。它可用于全局 archive 组织，但不再主导同一 pair 的局部收缩。

### 5.3 frontGap

令 pair 中点为：

```text
m = 0.5 * (f_norm(x_f) + f_norm(x_i))
```

`frontGap` 衡量该 pair 相对当前可行前沿搜索区域的位置。它越小，说明 pair 在 objective 上越值得继续参与竞争。

但 `frontGap` 不是可行/不可行边界的几何距离。它在最终版本中只表示 objective-side relevance：

* 局部 same-pair contraction 不使用 `frontGap` 作为接受规则；
* 全局覆盖、sector priority 和 infeasible selection 可以保留 `frontGap`，但只能把它当目标相关性量。

### 5.4 局部收缩 key 与全局排序 key 分离

同一 pair 的局部收缩只判断 bracket 是否变紧：

```text
accept if NewDecGap < OldDecGap
if tied, compare ObjPairGap
```

`frontGap` 不进入局部接受规则。

全局 archive 组织仍需要 objective relevance，sector 内候选可以使用：

```text
global key(pair) = [tightness, frontGap, stable_index]
```

其中 `tightness` 可由 pair gap / decision gap 的组合表达，`frontGap` 只负责避免 `B` 收进大量对 CPF 没价值的边界碎片。

## 6. B 的构造与全局重排

每代构造临时候选池：

```text
A_t = B ∪ PopulationC ∪ PopulationU ∪ OffspringC ∪ OffspringU
```

`A_t` 只是当代局部计算池，不是新的持久化 archive。

在 `A_t` 上：

1. 归一化目标；
2. 按参考向量关联目标空间扇区；
3. 在当前扇区及邻接扇区内分别抽取 feasible shell 与 infeasible shell；
4. 只在 shell 内构造 feasible-infeasible pair；
5. 先保证 pair 是异标签 bracket，再按 tightness 与 `frontGap` 得到目标相关的边界候选；
6. 依据扇区配额构造本代理想边界存档 `B*`；
7. 用 `BlendBoundaryArchive` 将当前 `B` 向 `B*` 平滑靠拢。

`PopulationU` 本体不进入 `PopulationC` 的候选池，但会进入 `A_t` 参与目标空间边界挖掘。这保持了 CCMO 式弱合作：辅助群体影响边界学习和 helper offspring，不直接污染主群体环境选择。

## 7. same-pair contraction

当前源码只把少量 helper offspring 替换为 B pair 的决策中点，然后把评估结果交给全局 B mining 重新竞争。`PRBCCMO-v2` 将其改为同 pair 持续收缩。

### 7.1 采样

从 active pairs 中选择需要精炼的 pair。优先级建议为：

```text
[decGap large, age large, frontGap small]
```

然后对同一批 pair 做连续二分，推荐内部固定：

```text
Kbis = 3
```

每次生成当前 bracket 的决策中点：

```text
x_ref = 0.5 * (x_f + x_i)
```

中点评估后立即更新同一 pair，再进入下一次二分。这样同样的 helper 预算会覆盖更少 pair，但每个 pair 会真正收缩多次。

### 7.2 接受准则

评估 `x_ref` 后，先构造候选 pair：

```text
if x_ref is feasible:
    candPair = (x_ref, x_i)
else:
    candPair = (x_f, x_ref)
```

然后比较 bracket 是否变紧：

```text
accept if DecisionDistance(candPair) < DecisionDistance(oldPair)
```

只有当候选 pair 保持 opposite-label 且 bracket 更紧时，才回写原 pair；若 `DecGap` 持平，再用 objective pair gap 作为次级比较。

这样 same-pair contraction 是单调的二分式逼边，不会再被 `frontGap` 把局部收缩目标带偏。

## 8. etaB 的新语义

`etaB` 应保留，但语义应收窄为：

```text
etaB_global = maximum cross-pair global reshape ratio
```

它只约束不同 pair 之间的全局新增、替换和丢弃，不约束同 pair 的局部逼边。

推荐主版本默认值：

```text
etaB_global = 0.05
```

`0.1 / 0.2` 可保留为消融对照。关键不是固定某个常数，而是把 same-pair contraction 从 `BlendBoundaryArchive` 的全局替换预算中剥离出来。

## 9. MLP 设计

### 9.1 训练集

MLP 的训练集来自固定长度训练缓冲区 `T`，不再只来自 `B`：

```text
T = current B endpoints
  + recent refinement points
  + small real boundary-band points
```

训练缓冲区规则：

* 当前全部 `B endpoints` 永远保留，是 MLP 的边界语义锚点；
* 最近若干代的 refinement points 优先加入，它们来自同一 pair 二分/收缩评估，标签真实；
* 剩余位置只放少量最近的 real boundary-band points，用于减轻纯 `B endpoints` 的分布过窄问题；
* 所有标签都来自真实评估，feasible 为 `1`，infeasible 为 `0`；
* `T` 固定长度，non-B 部分 FIFO 更新，不累计全部历史样本；
* FIFO 只作用于 non-B 样本，空间不足时先丢最旧 boundary-band，再丢最旧 refinement。

训练时做 batch 级 `1:1` feasible / infeasible 平衡。缓冲区本身仍保留原始来源和时间信息，诊断中需要报告未平衡前的正负样本数。

不新增 calibration archive、ranking loss、ensemble 或第二模型。`T` 是短期训练缓冲区，不是新的搜索种群，也不是无限历史 replay archive。

### 9.2 输入输出

* 输入：决策变量；
* 输出：`p(feasible | x)`；
* 归一化：使用 `Problem.lower / Problem.upper` 固定归一化。

### 9.3 网络结构

主版本保持轻量单隐层 MLP：

```text
hidden = 20
activation = tanh
output = sigmoid
loss = BCE
```

`hidden = 30 / 40` 只适合作为附录消融，不作为 v2 的核心机制。

### 9.4 训练时机

继续使用固定周期训练：

```text
Gstart = 20
Tretrain = 10
```

首次满足条件时冷启动，之后在旧模型上继续训练。若 `B` 的 pair 数不足、`T` 标签不全或 `T` 无法形成 1:1 训练 batch，则跳过本轮训练。

## 10. carry 位上的不可行选择压力恢复

当前源码在 `Feasible >= N` 时直接只选可行解并返回，导致许多问题上不可行分支完全没有触发。`PRBCCMO-v2` 不引入 dynamic relaxation，而是加入极小的 model-ready carry slot。

### 10.1 carry gate

carry slot 只在以下条件满足时开启：

```text
Infeasible pool is non-empty
B has enough active pairs
```

`ModelDegraded / acc_after` 只作为日志信号，不再硬关闭 carry。若模型尚未准备好，`p(feasible | x)` 可退化为常数先验，由 objective/geometric key 接管排序。

默认 carry 数为：

```text
Carry = min(max(1, round(0.01 * N)), numel(Infeasible))
```

当 `N = 100` 时，通常只保留 1 个不可行位。

### 10.2 选择方式

可行部分仍由 objective-based selection 负责，选择 `N - Carry` 个可行解。

carry 位只从不可行候选中选，最终排序使用统一 key：

```text
score(x) = p(feasible | x)
sort key = [FrontGap(x), -score(x), DistToB(x), index]
```

这意味着 MLP 负责恢复不可行选择压力，但不是唯一裁判。`FrontGap` 先保证 objective relevance，`DistToB` 作为稳定器避免远端 outlier。

sector round-robin 可以保留为外层多样性包装，但每个 sector 内和 fallback global 排序都使用同一个 key。

## 11. 不纳入主版本的机制

为保证因果链干净，以下机制不纳入 `PRBCCMO-v2` 主版本：

* 不把 `PopulationU` 本体并入 `QC`；
* 不把 helper 中点系统性偏向 infeasible 侧；
* 不引入 DRM 风格 dynamic relaxation；
* 不把 hidden 从 `20` 直接升到 `40` 作为主贡献；
* 不引入温度校准、ensemble、成对排序损失、第二模型或无限历史 replay archive。

这些机制可以作为后续消融或扩展讨论，但不应混入主版本，否则会削弱 “B 收缩 -> T 提供真实短期边界训练视野 -> MLP 概率先验参与统一排序” 的归因。

## 12. 核心观测指标

`PRBCCMO_t` 的 trace 应服务三个核心问题：

1. `B` 是否更贴近目标空间边界；
2. 不可行 carry 位是否确实被触发；
3. `T` 是否提供了足够、平衡且不过时的 MLP 训练视野；
4. carry 位上的统一排序是否带来正的概率增益。

建议保留或新增以下字段：

```text
b_pair_count
b_mean_pair_gap
b_p90_pair_gap
b_active_sector_ratio
b_changed_pair_count
b_changed_pair_ratio
mlp_trained
mlp_train_acc
train_size
train_pos
train_neg
train_src_b
train_src_refinement
train_src_boundary_band
inf_pool_size
inf_selected
inf_prob_gain
inf_carry_pool_size
inf_carry_applicable_count
inf_carry_selected
inf_carry_prob_gain
```

其中 `inf_carry_*` 必须与普通 infeasible fill 分开统计。否则当 `inf_selected=0` 或 `inf_prob_gain=NaN` 时，无法判断问题来自 carry 未开启、不可行候选池为空、模型不可用，还是选择逻辑没有真正执行。

## 13. 创新点

### 创新点 1：目标空间边界存档

PRBCCMO 将 unknown binary constraints 下的边界学习收束到目标空间，维护由 feasible / infeasible pair 组成的 `B`，避免把边界概念扩散到难以直接验证的决策空间约束几何。

### 创新点 2：严格 bracket 约束的同 pair 连续二分收缩

helper refinement 使用决策中点生成边界精炼样本，并固定对同一 pair 做连续二分。回写优先要求 opposite-label bracket 的 decision-space gap 变小，`frontGap` 不再干预局部收缩。

### 创新点 3：局部逼边与全局重排解耦

same-pair contraction 不受 `etaB_global` 限制；`etaB_global` 只控制跨 pair 的结构重排。这样既提升局部边界收缩速度，又保留 `B` 的全局稳定性。

### 创新点 4：固定长度 T 训练缓冲区上的连续边界分类器

MLP 由 `T = B + recent refinement + small real boundary-band` 训练，使用固定归一化和 plain BCE。`B endpoints` 保证语义锚点，recent refinement 提供最新边界形状，少量 real boundary-band 缓解外推；模型能力来自训练分布改进，而不是更复杂的网络或额外损失。

### 创新点 5：统一 key 下的不可行选择压力恢复

model-ready 后，主群体保留极小不可行 carry 位，并在该位上用 `[FrontGap, -p(feasible|x), DistToB]` 统一排序。这个设计让不可行选择分支稳定触发，同时避免 MLP 变成远端 outlier 的唯一裁判。
