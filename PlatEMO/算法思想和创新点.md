# PRBCCMO-R2：Pair-Supported Boundary Recoverability CCMO

## 1. 论文一句话

在二元未知约束多目标优化中，利用扇区化 feasible-infeasible witness pairs 持续提取与 CPF 搜索相关的局部边界证据，并在该证据带上训练一个轻量 MLP；该 MLP 不负责造边界，只在边界已覆盖的扇区内为不可行候选恢复相对于 learned boundary 的选择压力。 ([ACM Digital Library][2])

## 2. 最终定位

* 不是 **MLP 驱动边界采样**。
* 不是 **MLP 直接预测不可行解价值**。
* 不是 **双种群本身就是创新点**。
* 而是：

```text
pair-supported boundary evidence
→ boundary-band MLP
→ boundary-depth ranking on infeasible candidates
→ infeasible selection-pressure recovery
```

## 3. 核心创新点

### 创新点 1：Pair-supported local boundary evidence

边界不是由 MLP 猜出来的，而是由真实评估得到的 feasible-infeasible witness pairs 支撑出来的。算法只手工保留最小证据链：

```text
local witness pair
→ midpoint contraction
→ one short bisection
→ final bracket pair
```

### 创新点 2：Boundary-band recoverability learning

MLP 不做全局“可行/不可行价值分类器”，只在 **pair-supported boundary band** 上学习一个 boundary-centered score。

对当前已评估为不可行的候选 `x`，不再解释 `p(x)` 本身，而解释

```text
margin(x) = 2 * |p(x) - 0.5|
```

在**已覆盖扇区**内，`margin` 越小，表示 `x` 越接近 learned boundary，越可能是“可恢复、可穿越、值得保留”的不可行解。

### 创新点 3：Train thin, apply wider, trust locally

MLP 的三个区域必须区分：

* **训练区域**：薄的、pair-supported 的局部边界带
* **使用区域**：当前 `Q_C` 中的不可行候选池
* **可信区域**：仅限于边界已覆盖扇区内的候选

也就是说：

> **训练薄带，使用宽池，解释局部。**

这就回答了你前面的疑问：MLP 不是只能给薄边界带打分；它可以给**边界之外的不可行解**排序，但只能在**已覆盖扇区**里做有根据的排序，不能对整个搜索空间做无条件外推。

## 4. 算法对象

```text
P_C : constrained population，主群体，负责走向 CPF
P_U : unconstrained population，辅助群体，负责保持目标探索和跨越不可行区
B   : pair-level thin boundary memory，搜索用薄边界记忆
D   : PairBuffer，MLP 学习用的成对边界证据缓存
M   : lightweight calibrated MLP
```

关键约束：

```text
B 不是第三种群
B 不是边界拟合曲线
B 不是训练集全集
D 才是训练容器
```

## 5. MLP 的训练区域、使用区域、可信区域

### 5.1 训练区域

训练样本只来自 `D`，而 `D` 只来自：

```text
当代 PairEvents.finalPairs
+ revalidated B pairs
```

不直接把 `P_C` 或 `P_U` 全量塞进训练集。

### 5.2 使用区域

MLP 的使用对象不是 `B`，也不是 `D` 本身，而是：

```text
I_t = infeasible solutions in Q_C
Q_C = P_C ∪ O_C ∪ O_U ∪ O_B
```

也就是说，**当前进化产生的不可行候选**都可以被排序，包括边界之外的不可行解。

### 5.3 可信区域

但不是所有不可行解都无条件可信。只对以下候选应用 MLP：

```text
sectorCovered(x) = true
```

其中 `sectorCovered(x)` 表示：`x` 所在扇区，或其邻接扇区，当前已经有 `B` 或 `D` 提供的有效 boundary pair 支撑。

最终排序时再用 `supportDistDec(x)` 作为第二关键字抑制远外推。

## 6. 手工边界证据的最终设计

### 6.1 Witness pair 构造

候选池：

```text
A = unique(B ∪ P_C ∪ P_U)
```

对 `A` 进行参考向量扇区划分，仅允许在：

```text
same sector 或 neighbor sector
```

内做 feasible / infeasible 配对。

### 6.2 Pair gap

对 feasible-infeasible pair `(x_f, x_i)` 定义：

```text
d_x = ||x_f - x_i|| / scale_x
d_f = ||f(x_f) - f(x_i)|| / scale_f
pairGap = d_x + 0.25 * d_f
```

其中 `scale_x` 和 `scale_f` 用**确定性** median 距离估计，不用随机抽样。

`d_x` 是主项；`d_f` 只是防止跨 PF 区域乱配对。

### 6.3 配对规则

采用：

```text
mutual nearest cross-label pairing
```

若某个扇区没有 mutual pair，但存在 cross-label 个体，则仅保留该扇区最小 `pairGap` 的一对作为 fallback。

### 6.4 Pair 优先级

MLP 不参与这里。

对每个 pair 计算中点 `x_mid`，并定义：

```text
frontGap(pair) = scalar(x_mid) - best feasible scalar in local sector
```

若该扇区当前没有 feasible 解，则 `frontGap = 0`。

pair 排序键：

```text
[frontGap, pairGap, recency]
```

### 6.5 边界预算

```text
boundary_budget = floor(rho * N)
n_pair = floor(boundary_budget / 2)
```

按扇区 round-robin 取 pair，每轮每扇区最多取 1 对，预算没用完再进入下一轮。

### 6.6 边界子代生成

每对 pair 最多只做两次真实评估：

```text
x_m = 0.5 * (x_f + x_i)
evaluate x_m

if x_m feasible:
    x_b = 0.5 * (x_m + x_i)
else:
    x_b = 0.5 * (x_f + x_m)

evaluate x_b
```

只做一次短二分，不递归。

然后更新为最终 bracket pair：

```text
finalPair = nearest feasible side + nearest infeasible side
```

### 6.7 PairEvents

每代产生：

```text
E_t.finalPairs
E_t.probes
E_t.meta = {sector, pairGap, frontGap, time}
```

其中 `O_B` 只由当代通过 loose evidence gate 的新 probe 构成。

## 7. 薄边界记忆 B

### 7.1 单位

`B` 的基本单位是 **pair**，不是点。

### 7.2 Admission

只用几何 gate：

```text
pairGap <= tau_B
```

不使用：

```text
margin
probability
MLP score
```

### 7.3 容量

推荐默认：

```text
kappaPair = 3  % each sector keeps at most 3 pairs
```

即每扇区最多保留 6 个边界点，而不是当前那种点级 `kappa=10` 厚边界云。

### 7.4 排序

每扇区 pair 排序键：

```text
[sourcePriority, frontGap, pairGap, -time]
```

其中：

```text
sourcePriority:
1 = new final pair from E_t
2 = revalidated old pair from B
```

## 8. MLP 设计

### 8.1 结构

保留当前轻量实现，不引入 Deep Ensemble 作为主版本。

```text
Input  : normalized decision vector only
Hidden : one hidden layer
Act    : tanh
Output : sigmoid
```

默认可以继续保留当前 `hidden=20`；若要统一高维尺度，可改为：

```text
hidden = min(40, max(20, D))
```

BE-CBO 使用更强的集成模型，是因为它让模型承担显式边界探索；而本算法的路线 2 不让模型负责采样，因此没必要把主版本改成重模型。([Proceedings of Machine Learning Research][1])

### 8.2 输入

只用决策变量，不输入：

```text
objective
sector id
frontGap
supportDist
```

这些都属于选择层，不属于边界分类层。

### 8.3 标签与训练集

训练集由 `D` 展开而来，每个 pair 贡献：

```text
x_f -> label 1
x_i -> label 0
```

### 8.4 损失

使用 weighted BCE：

```text
w_pair = 1 / (1 + pairGap)
```

tight pair 权重大，loose pair 权重小。

### 8.5 训练策略

保留当前实现里的：

```text
normalization rebase warm-start
temperature scaling
```

只简化触发逻辑：

* 首次训练条件：

  * `pair_count >= 10`
  * `mixed_sector_count >= 3`
  * 正负标签都存在

* 后续重训：

  * 每 `10` 代检查一次
  * 若 `new_pair_ratio >= 0.2` 则重训

不再把复杂 validation 触发作为主逻辑。

## 9. 不可行解选择压力恢复

### 9.1 Model-applicable infeasible set

对 `Q_C` 中不可行候选，定义：

```text
ApplicableI = { x infeasible | sectorCovered(x) = true }
```

注意：

```text
这里不要求 x 自己已经构成 tight pair
也不要求 x 自己已经进入 B
```

### 9.2 排序语义

若 `M` 已就绪：

```text
sort by [margin, supportDistDec, frontGap, diversity]
```

若 `M` 未就绪：

```text
sort by [supportDistDec, frontGap, diversity]
```

其中：

* `margin`：相对 learned boundary 的浅深
* `supportDistDec`：离最近 pair center / boundary support 的距离
* `frontGap`：目标上离当前 feasible frontier 的相关性差距

### 9.3 解释

这里的 `margin` 不表示“价值”，只表示：

```text
在边界已覆盖扇区内，
该不可行解离 learned boundary 有多深
```

因此它能给**边界之外的不可行解**排序，但这个排序是：

```text
boundary-depth ranking
```

而不是：

```text
global predicted value ranking
```

## 10. 最终算法流程

```text
Algorithm PRBCCMO-R2

Initialize:
    P_C, P_U
    B = empty pair-level thin boundary memory
    D = empty PairBuffer
    M = null

while termination not met:

    1) Standard offspring
       O_C <- DE(P_C)
       O_U <- DE(P_U)

    2) Pair-supported boundary evidence generation
       A <- unique(B ∪ P_C ∪ P_U)
       PairSet <- BuildLocalWitnessPairs(A)
       PairSet <- sort by [frontGap, pairGap, recency]
       SelectedPairs <- SectorRoundRobin(PairSet, floor(rho*N/2))
       E_t <- MidpointAndOneShortBisection(SelectedPairs)
       O_B <- new evaluated probes in E_t passing loose gate

    3) Environmental selection for constrained population
       Q_C <- unique(P_C ∪ O_C ∪ O_U ∪ O_B)
       F   <- feasible(Q_C)

       if |F| >= N:
           P_C <- objective MOEA selection on F
       else:
           P_C <- F
           Need <- N - |F|
           I_app <- applicable infeasible in Q_C

           if M ready:
               rank I_app by [margin, supportDistDec, frontGap, diversity]
           else:
               rank I_app by [supportDistDec, frontGap, diversity]

           P_C <- P_C ∪ top Need from I_app
           if still not full:
               fill from remaining Q_C by objective selection

    4) Environmental selection for helper population
       Q_U <- unique(P_U ∪ O_C ∪ O_U ∪ O_B)
       P_U <- objective-only MOEA selection on Q_U

    5) Boundary memory update
       B <- keep top kappaPair pairs per sector from
            [new finalPairs in E_t, revalidated old pairs]

    6) PairBuffer update
       D <- append [E_t.finalPairs, selected B pairs]
       D <- trim by sector balance, pairGap, recency

    7) MLP update
       if training trigger satisfied:
           M <- train calibrated lightweight MLP on D

Output:
    feasible nondominated solutions in P_C
```

```text
MLP in boundary sampling
MLP in archive admission or archive ranking
global P_C/P_U training source
point-level thick archive with side quota
complex objScore mixture

model-generated boundary points
```
