# EADMM/MOEA/D 当前主线

当前任务入口为 `EADMMMOEAD.m`。采用用户于 2026-10-24 接受的本地复现配置；本次不继续调整参数、问题或 IGD 参考集。目录中的 NSGA-II/IBEA 是其他骨架入口，论文依据与尚未确认的作者细节见 `REPRODUCTION_NOTES.md`。

## 参数与流程

- 入口参数 `{localN,weightFloor}` 默认 `{0,1e-4}`。localN=0 时 D<=5 取 50，否则取 200；本次 UC 验证配置实际均为 200。局部 GA 的其他选项保持原值。
- NBI 生成共享权重，权重下限 1e-4 后逐行归一化；以实际权重数更新 N。邻域大小为 `max(2,ceil(N/10))`。两个种群独立初始化。
- 模块一依次遍历各子问题，用当前子问题解和一个随机邻居进行 SBX/多项式变异（概率 1、分布指数 20，变异概率 `1/D`）。主种群按四条约束替换规则更新源子问题的邻域；不能把这些顺序更新改为同时更新。
- 模块二用同样的繁殖方式演化无约束辅助种群，按 modified Tchebycheff 替换邻居。聚合函数为 `max(abs(f-Z)./W)`。
- 主任务每次用当前 `P1 ∪ {candidate}` 的逐目标最小值作为理想点；辅助任务保留历史理想点 Z2。这两个更新规则不同。
- 模块三先交换两个任务的后代，仍更新各后代原始子问题的邻域；再选出同时支配主种群至少一个解、辅助种群至少一个解的主任务后代作为临时档案。两个被支配解不要求相同。
- 对每个档案中心独立运行完整 MATLAB `ga`，最小化“违反约束的数量 + rho × 到中心的平方距离”，`rho=(主种群可行人数/N)×约束信号列数`。GA 仍在完整变量边界中搜索，不注入中心，不跳过约束查询。
- GA 内部只调用决策修复和约束查询；最后一个局部解进行一次完整评价并计入外层 FE，再反馈到两个种群的原始来源邻域。保持完整一代后才检查终止的行为。

## 本次执行层优化

热点位于 `EADMMLocalSearch.m`。仅当反射确认问题继承 `PROBLEM.CalDec` 时，在单行 GA 回调中直接执行相同顺序的边界裁剪与整数修复，避免重复 `repmat`、`ismember` 和方法调用。上下界、编码仍每次读取；自定义 `CalDec` 继续原样调用。局部结果用预分配 cell 按原顺序收集。

共享局部搜索函数的接口、GA 参数、适应度表达式、约束查询顺序、RNG 消耗及外层 FE 均保持不变。没有新增实验开关、生产日志或过程 IGD 计算。

完整预算验证覆盖 UC1-C1-DTLZ1/M2、UC1-C3-DTLZ2/M5、UC2-C3-DTLZ1/M2，最终种群、FE、目标/约束查询数、IGD、RNG 与提速前一致；最后一题另核对 199 个代际状态。混合编码与带随机操作的自定义修复测试也保持查询序列一致。计时、源码哈希和验证范围见 `Experiments/NAEMT_EADMM_ExactSpeed_20261024/REPORT.md`（相对 PlatEMO 根目录）。
