# EADMM/MOEA/D 当前主线

当前任务入口为 `EADMMMOEAD.m`。保留原外层GA及2026-10-31补充的外层DE模式；2026-11-02按用户选择采用局部GA“200人／最多20代／停滞窗口5代”。目录中的 NSGA-II/IBEA 是其他骨架入口，论文依据与尚未确认的作者细节见 `REPRODUCTION_NOTES.md`。

## 参数与流程

- 入口参数 `{type,localN,weightFloor}` 默认 `{1,200,1e-4}`。type=1为原外层GA，type=2为外层DE；两种模式的局部GA均设为`MaxGenerations=20`、`MaxStallGenerations=5`，`FunctionTolerance=1e-6`。停滞窗口检查最佳适应度的平均相对变化，不是严格“连续5代零改善”。
- `localN`仍可显式指定；传0保留旧兼容行为：D<=5取50，否则取200。默认调用使用200人，与D无关。
- NBI 生成共享权重，权重下限 1e-4 后逐行归一化；以实际权重数更新 N。邻域大小为 `max(2,ceil(N/10))`。两个种群独立初始化。
- type=1的模块一依次遍历各子问题，用当前子问题解和一个随机邻居进行原SBX/多项式变异（概率 1、分布指数 20，变异概率 `1/D`）。主种群按四条约束替换规则更新源子问题的邻域；不能把这些顺序更新改为同时更新。
- 模块二用同样的繁殖方式演化无约束辅助种群，按 modified Tchebycheff 替换邻居。聚合函数为 `max(abs(f-Z)./W)`。
- type=2的两个外层模块调用通用目录原生默认 `OperatorDE`，保留当前子问题作为基向量，使用随机邻域顺序中的两个其他个体作差分。邻域只有两人时，从种群中排除已有两个索引后随机补第三个，不改变邻域大小及替换范围；DE要求实际种群至少3人。每个子问题仍只生成一个子代。
- 主任务每次用当前 `P1 ∪ {candidate}` 的逐目标最小值作为理想点；辅助任务保留历史理想点 Z2。这两个更新规则不同。
- 模块三先交换两个任务的后代，仍更新各后代原始子问题的邻域；再选出同时支配主种群至少一个解、辅助种群至少一个解的主任务后代作为临时档案。两个被支配解不要求相同。
- 对每个档案中心独立运行上述预算的MATLAB `ga`，最小化“违反约束的数量 + rho × 到中心的平方距离”，`rho=(主种群可行人数/N)×约束信号列数`。GA 仍在完整变量边界中随机初始化，不注入中心，未启用达到0停止的候选设置。
- GA 内部只调用决策修复和约束查询；最后一个局部解进行一次完整评价并计入外层 FE，再反馈到两个种群的原始来源邻域。保持完整一代后才检查终止的行为。

## 此前执行层优化

热点位于 `EADMMLocalSearch.m`。仅当反射确认问题继承 `PROBLEM.CalDec` 时，在单行 GA 回调中直接执行相同顺序的边界裁剪与整数修复，避免重复 `repmat`、`ismember` 和方法调用。上下界、编码仍每次读取；自定义 `CalDec` 继续原样调用。局部结果用预分配 cell 按原顺序收集。

2026-10-24的执行层提速保持了当时的GA参数、适应度、查询顺序、RNG和FE。此次选用20/5预算会改变相对于旧100D/50设置的搜索轨迹；生产代码仍不含实验开关、日志或过程IGD计算。

完整预算验证覆盖 UC1-C1-DTLZ1/M2、UC1-C3-DTLZ2/M5、UC2-C3-DTLZ1/M2，最终种群、FE、目标/约束查询数、IGD、RNG 与提速前一致；最后一题另核对 199 个代际状态。混合编码与带随机操作的自定义修复测试也保持查询序列一致。计时、源码哈希和验证范围见 `Experiments/NAEMT_EADMM_ExactSpeed_20261024/REPORT.md`（相对 PlatEMO 根目录）。

## 算子接口与比较口径

```matlab
A = EADMMMOEAD();                    % 默认：原外层GA模式
A = EADMMMOEAD('parameter',{2});     % 新增外层DE模式
A = EADMMMOEAD('parameter',{2,200,1e-4}); % 显式指定全部参数
```

论文数值比较对应type=1。两种外层模式都调用MATLAB `ga`进行内部局部优化，使用相同的20/5预算。外层GA/DE、选择和反馈流程保持原实现。EADMMNSGAII、EADMMIBEA继续使用共享函数的旧默认预算100D/50。此前算子扩展见[验证报告](../../../Experiments/Comparators_PreserveOperators_20261031/REPORT.md)。

## 局部GA简化研究（2026-11-02）

原200/100D/50是通用`ga`默认值推定。13组候选的153次完整预算运行保存在[选型研究报告](../../../Experiments/EADMM_LocalGA_Simplify_20261102/REPORT.md)。选型阶段按原门槛暂不采用候选，随后用户明确指示使用200/20/5，因此当前按此选择实施。

所选方案已有36配置seed1结果：论文±10%内29/36、±20%内33/36，全部约束查询由632,880,841降至64,422,667（减少89.8%）。这是查询成本比较，不是墙钟提速或作者统计等效证明。当前生产实现与所选快照的核对见[采用验证](../../../Experiments/EADMM_LocalGA_Adopt_20261102/REPORT.md)。
