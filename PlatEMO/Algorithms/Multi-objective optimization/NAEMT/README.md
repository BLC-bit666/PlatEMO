# NA-EMT 当前主线

入口为 `NAEMT.m`。以用户于2026-10-24接受的本地复现配置为原DE模式；2026-10-31仅补充GA选择入口，原DE及训练机制保持不变。论文明确规定与本地补齐细节的边界见 `REPRODUCTION_NOTES.md`。

## 参数与流程

- 入口参数 `{type,alpha,epsilon,N1,K}` 默认 `{1,1,1-eps(1),1000,1}`；type=1为新增GA，type=2为原DE。旧参数现在从第二位开始。DE保留 `CR=1,F=0.5`、K及原多项式变异概率 `1/D`、指数20；K只影响DE。
- 先真实评价 1000 个训练样本。`cons<=0` 为可行，训练标签可行 1、不可行 0。训练 D–10–1 MLP：ReLU、sigmoid、交叉熵、`trainscg`，80% 训练/20% 测试，保持 MATLAB 原训练准则与输入预处理。
- 再独立初始化主、辅两个 N 人种群。主任务中，可行解的 Value 为 1，不可行解的 Value 来自 MLP。
- type=2：每代两个种群各生成 N 个原DE后代；三个随机索引与当前个体互异。计算顺序保持 `x + K*(x_r1-x) + F*(x_r2-x_r3)`，再交叉、强制一个坐标、多项式变异及边界修复。当前 K=1 在数学上退化为 rand/1，代码保留上述浮点计算顺序。
- type=1：对每个当前位置，从其他个体中均匀选取两个互异父代，调用通用目录原生默认 `OperatorGAhalf`；两种群各产生N个子代。没有新增自定义交叉或变异。
- 主种群从 `[P1,O1,O2]` 按 CDPPV 和拥挤距离选 N 人。Value 大于等于 epsilon 的组按 Pareto 支配比较，且优于低置信组；低置信组中 Value 大者优先。
- 辅种群从 `[P2,O2,O1]` 按无约束 NSGA-II 选择 N 人。两个种群的拼接、并列解顺序和拥挤距离计算保持不变。
- 最近 10 代的原始后代组成滚动档案。对本代可行后代计算 `accuracy=1-mean(abs(1-prediction))`；没有可行后代时为 NaN。
- accuracy 可观测且小于 alpha、主种群尚未全可行、档案同时有两类样本时，分别抽取 100 个可行/不可行样本，按 FIFO 更新固定 1000 行训练集。非空类别不足配额时有放回抽样。热启动续训后立即重算主种群的 Value。
- 保持整代终止检查和 FE 消耗；每代 2N 次真实评价，训练和预测不增加 FE。

## 此前执行层优化

`NAEMTCDPPVNDSort.m` 用逻辑支配矩阵替代逐对函数调用及动态支配列表，按完全相同的支配关系逐层剥离。两个环境选择函数各读取一次目标矩阵。辅助排序保持原 `NDSort`；尝试过的二维矩阵排序没有稳定整程收益，未采用。

正式实现没有实验日志、性能 IGD 计算或候选策略开关。accuracy、档案类别检查、训练集 80/20 划分、输入与非有限值检查均为正常流程或必要校验，不属于可删除的实验诊断。

固定种子的九题完整 200000 FE 重放与提速前的最终种群、FE、IGD、RNG 一致。DASCMOP4_BC/8_BC 另各核对 995 个代际状态，包括两个种群、预测值、网络权重和输入预处理、训练数据、滚动档案、RNG。计时、源码哈希和边界检查见 `Experiments/NAEMT_EADMM_ExactSpeed_20261024/REPORT.md`（相对 PlatEMO 根目录）。

## 算子接口与比较口径

```matlab
A = NAEMT();                  % 默认：新增GA模式
A = NAEMT('parameter',{2});   % 原DE模式及原训练默认参数
A = NAEMT('parameter',{2,1,1-eps(1),1000,1}); % 显式指定全部参数
```

原NA-EMT基线与此前DE结果对应type=2。type=1属于GA扩展版，应单独标注；原自定义 `NAEMTOperatorDE`、MLP训练、CDPPV、辅助选择和档案更新均保留。入口核对通用算子路径，仅新增GA使用通用默认设置，不改写原DE设计。此前完整IGD等价结论属于对应历史版本；本次原模式回归范围见[验证报告](../../../Experiments/Comparators_PreserveOperators_20261031/REPORT.md)。
