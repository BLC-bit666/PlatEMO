# GANCMO：唯一保留主线

正式入口为同目录 `GANCMO.m`。唯一主线为 **G=sin、D=LeakyReLU(0.2)**；G 使用 D 维噪声与 M+1 维条件拼接输入。固定参数在 `GANCMOSettings.m`，不提供版本切换或外部覆盖。

当前激活选型已完成 LIRCMOP7_BC/8_BC 各 5 次完整运行，sin 主线的最终与过程 IGD 均值均优于 ReLU/ReLU，详见 [选型结论](../../../Experiments/GANCMO_Activation_20261008/CONCLUSIONS.md)。当前主线已通过优化前后 20 次完整搜索验证：两题各 5 组种子的轨迹、最终与过程 IGD 均精确一致；平均完整耗时减少 19.89%，其中 7_BC 减少 17.13%、8_BC 减少 22.42%，10 组配对均更快。详见 [验证报告](../../../Experiments/GANCMO_Speed_20261009/REPORT.md)；耗时结论限于该源码、配置与本机环境。

## 算法流程

P1 按约束选择，P2 忽略约束；两者容量均为 N。每代总计 N 个新评价，通常各 N/2 个；预算尾部按剩余 FE 截断。P1 的 CGAN 计划比例为 `0.1+0.8*p`，其中 `p=(FE-初始FE)/(maxFE-初始FE)`。候选不足由 DE 补齐，P2 全部使用 DE。两种群共享 DE 子代；CGAN 子代只参与 P1 选择。CGAN 不调用 GA，不经过 DE 二次加工。

每代先用当前存档决定是否训练和生成，再评价子代、选择两个种群，并以选择前的完整已评价并集更新存档。训练、查询和 DE 使用独立随机流。

运行时前向计算使用 `fullyconnect`、`sin`、`leakyrelu`；`dlnetwork` 用于初始化与保存网络结构；每次训练事件内复用参数数组，执行自动微分和 MATLAB `adamupdate`，事件结束后写回网络与优化器状态。G 的直接前向与网络图均对 `[z;c]` 执行全连接、sine、全连接运算。F/I 两侧共享同一输入路径，无独立噪声支路、固定噪声增益或输出端噪声相加。

## 存档与条件

- 固定原始目标坐标（minimum=0、span=1）；参考方向由 `UniformPoint(N,M)` 产生。M=2 时 N=100 得到 100 个方向，M=3 时为 91 个。
- 新旧端点合并后一次检查合法性：F 属于合并可行池的非支配前沿，I 不被该前沿支配；P1 归属不放宽端点资格。初始化及后续更新使用同一规则，无 10% FE 切换。
- 每个合格 F 寻找最近合法 I，邻域共 5 个参考方向，包含本方向；距离使用原始目标空间欧氏距离。每方向始终按 F 是否属于当前 P1、方向上的目标质量及 F/I 距离筛选配对前沿，再选最近活动对。
- 空方向可以建对；通过端点资格和配对前沿筛选的合法旧对只接受严格更短的替代，同距优先保留旧对；旧对在上述筛选中失效后允许重建，重建距离可以增大。存档容量仍为 500，故不宣称所有方向距离无条件单调下降。
- 每方向恰好一个活动对；全部合法活动对参与训练。首训门槛固定 **8 对**，无 20 对上限，无目标距离日程或训练距离筛选；续训门槛为 2 对。
- 条件为 **M 维单位参考向量＋真实可行性 0/1**，共 M+1 维；噪声维数始终为 D。查询使用可行侧条件 1，但生成点仍需真实约束评价。

## 全部固定参数

| 项目 | 参数 |
|---|---|
| 统一运行配置 | N=100，D=30，maxFE=150000；完整对照口径为 runs=5，种子 1–5，10 个进程 worker，每 worker 1 个计算线程 |
| 子代 | P1=50，P2=50，总计 100 FE/代；初始化 200 FE，完整搜索 1498 代 |
| DE | `OperatorDE` 默认 CR=1、F=0.5、proM=1、disM=20；不同父代索引，二元锦标赛 |
| 生成器 | `[z;c]` 共 D+M+1 维，`(D+M+1)→128→D`，sine 激活，线性输出 |
| 噪声 | D 维正态输入，sigma=0.02；F/I 两侧均经第一层可学习权重进入隐藏层 |
| 初始化 | 首层噪声列采用 Glorot 均匀边界 `sqrt(6/(D+M+1+128))`；参考向量列保留 256 倍正态初始化，侧标签列保留 `[0,2*pi)` 均匀初始化。256 不是每层的正弦频率乘数 |
| 判别器 | `(D+M+1)→16→1`，leakyReLU(0.2)，无界标量输出 |
| 可学习参数量 | G 与 D 合计：D=30 时，M=2 为 8783，M=3 为 8927 |
| 训练触发 | 首次 8 对；之后至少 2 对，间隔达到 20 代或内容变化达到 0.2；无重置 |
| 更新次数 | 首训 G=6000；续训 G=1000；每次 G 对应 C=2 次 |
| 批次 | K 个活动对时批量为 2K，F/I 各 K 条；方向组均衡抽样，相同真实端点去重 |
| 学习率、Adam | 每次训练事件内指数衰减 0.001→0.000001；β1=0、β2=0.9 |
| C 损失 | WGAN＋GP×10；梯度范数根号稳定项 1e-12 |
| G 损失 | −平均 C 分数＋100×同方向同真实侧最近端点 RMS；根号稳定项 1e-8 |
| 内容变化 | 保留原双向最近移动平均，除以 `max(旧决策距离,1e-3*sqrt(D))`；条件改变记作 1，再对方向取平均 |
| 候选查询 | 500 个，按全部参考方向均分；不能整除时将余数随机分给不同方向，次数相差不超过 1。模型可用后不受当前与上次训练方向交集限制，当前无激活对也可查询 |
| 基础筛选 | 两类方向均检查有限值、裁至问题变量边界，并与 P1/P2、全部存档端点及已选候选去重；归一化决策去重距离 >1e-6 |
| 有激活对方向 | 当前全部激活对的 F/I 两侧端点逐维 min/max 建共同盒，容差 1e-12；非激活备份对不扩盒。该请求方向的盒外候选淘汰、不投影；盒内按距离对应 F 从近到远排序，无距 F 硬门槛 |
| 无激活对方向 | 不受存档盒子限制；用原判别器按条件 `[单位参考向量,1]` 的分数从高到低排序。输入决策沿用训练的 [-1,1] 归一化；不设分数阈值，有限负分也可入选，不跨方向比较分数 |
| 名额分配 | 随机排列请求方向，每方向至多选 1 个；最优候选与已选点重复时尝试本方向下一候选。两类方向共用原 G 总配额，无盒内/盒外或探索独立名额，不足由 DE 补齐 |
| 存档数值边界 | 决策距离平方 >1e-24；边界容差 1e-12；I 端点支配筛选容差 1e-12 |

## 使用与验证

按 PlatEMO 的通常方式添加依赖后可用 `GANCMO`。不要递归添加 `Experiments`，避免历史同名函数遮蔽。

```matlab
P = LIRCMOP7_BC('N',100,'D',30,'maxFE',150000,'maxRuntime',Inf);
A = GANCMO('save',-75,'outputFcn',@(varargin)[]);
A.RecordTrace = true;   % 可选诊断，不影响搜索
A.Solve(P);
```

根目录 `test.m` 仅执行局部回归，不重新运行完整实验或覆盖历史证据。网络回归覆盖 D=3/30、M=2/3，检查两侧噪声的非线性梯度、续训时噪声输入权重更新，以及 G/D 直接前向与网络图一致性。候选回归验证全方向均匀查询及随机余数、有激活对方向的共同盒、无激活对方向的盒外保留、F/D 两种排序、负分入选、共享配额、去重以及筛选不调用目标或约束。存档回归验证严格 F/I 资格、初始化即执行配对前沿、距离优先及旧对失效后的同距重建。激活函数选型和速度优化均已完成当前结构的完整验证。优化前后每次 75 个检查点的决策、目标、约束、IGD，以及逐代生成点、存档、训练次数、最终网络、Adam 和 RNG 均精确一致；20 次均达到 150000 FE，无失败或非有限 IGD。

`Trace.generated` 中 `requestedRef` 才是评价前的名额分组依据；真实生成点方向由评价后目标值统计。`targetRef` 仅记录对应 F 的关联方向，无激活对时为 0，不参与限额。`hasActivePair` 标记筛选分支；有激活对记录 `distanceF`、无激活对记录 `criticScore`，另一项为 NaN。`queryCounts` 记录全部参考方向的查询次数，`diverseCandidates` 记录基础筛选后有候选的请求方向数。D 分数仅作方向内弱排序，不代表可行概率或目标质量。

最终 IGD 为 150000 FE 末点；过程 IGD 为 `trapz(20000:2000:150000,IGD)/130000`，越小越好。保持全部 5 次，不剔除失败或非有限值。局部回归只验证实现，不证明 IGD 或速度改进。
