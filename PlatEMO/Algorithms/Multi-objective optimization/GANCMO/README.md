# GANCMO 唯一主线

正式入口为 `GANCMO.m`，固定配置为 **G=128、Critic=16、初训6000、续训1000**。采用动态历史理想点Z、全部存档训练和F质量优先代表；`GANCMOSettings.m`是唯一参数定义，没有版本切换或外部覆盖。

两题五种子参数选型已结束，结论及全部数据见[最终选型报告](../../../Experiments/GANCMO_AdaptiveParameters_20261009/FINAL_REPORT.md)。本轮清理和等价提速的验证状态见[实验目录](../../../Experiments/GANCMO_CleanupSpeed_20261010/README.md)。

## 算法流程

P1 按约束选择，P2 忽略约束；两者容量均为 N。每代总计 N 个新评价，通常各 N/2 个；预算尾部按剩余 FE 截断。P1 的 CGAN 计划比例为 `0.1+0.8*p`，其中 `p=(FE-初始FE)/(maxFE-初始FE)`。候选不足由 DE 补齐，P2 全部使用 DE。两种群共享 DE 子代；CGAN 子代只参与 P1 选择。CGAN 不调用 GA，不经过 DE 二次加工。

初始化后，以 P1/P2 全部目标值的逐列最小值建立 Z。每代先用当前存档决定是否训练和生成，评价全部子代后更新 Z，再选择两个种群，并以选择前的完整已评价并集更新存档。Z 取历史最小值，包含不可行、未被种群或存档保留的已评价解。批量取最小值与逐个子代更新等价；本代训练和查询共用代初的原点，存档更新采用评价后的原点。训练、查询和 DE 使用独立随机流。

运行时前向计算使用 `fullyconnect`、`sin`、`leakyrelu`；自动微分只跟踪本次更新所需变量：Critic步骤跟踪Critic参数和插值决策，G步骤只跟踪G参数；其余输入仍参与原有前向和损失计算，但无需计算它们的梯度。`dlnetwork` 用于初始化与保存网络结构；每次训练事件内复用参数数组，仅缓存G/Critic前向算子的执行图，损失及求梯度顺序保持原样；执行自动微分和 MATLAB `adamupdate`，事件结束后写回网络与优化器状态。G 的直接前向与网络图均对 `[z;c]` 执行全连接、sine、全连接运算。F/I 两侧共享同一输入路径，无独立噪声支路、固定噪声增益或输出端噪声相加。

## 存档与条件

- 参考方向由 `UniformPoint(N,M)` 创建一次并保持固定，使用返回的方向数，不修改种群 N。N=100 时，M=2 得到 100 个方向，M=3 为 91 个。
- `Scale.minimum=Z`、`Scale.span=1`，目标只作 `f-Z` 平移，不压缩到 [0,1]。每次存档更新都用当前 Z 重新分配全部新旧 F/I 端点的最小夹角方向，配对 `ref` 取 F 方向。零向量沿用确定性归属规则。方向邻域按 W 的夹角取最近 5 个，含自身，保持固定。
- 新旧端点合并后一次检查合法性：F 属于合并可行池的非支配前沿，I 不被该前沿支配；P1 归属不放宽端点资格。初始化及后续更新使用同一规则，无 10% FE 切换。
- 旧对的两端须在当前方向邻域内；迁移后不满足条件的旧对移除，其端点仍在本次合并池中参与资格筛选和重新配对。
- 每个合格 F 在上述邻域内寻找目标距离最近的合法 I。新对与合法旧对合并去重，每方向按“F 是否属于当前 P1、F 目标质量、F/I 目标间距”筛选非支配配对前沿。
- 每对只保存 `ref`、`xf`、`yf`、`xi`、`yi`；配对间距与 P1 归属按需计算。全部保留的合法对都用于训练，不保存编号、活动状态或转移标记。
- 每方向选一个候选指导代表：优先最小化 `max((yf-Z)./(W(ref,:)+1e-12))`，再比较原始目标空间 F/I 欧氏距离。两项相同优先保留仍合法的旧代表，之后比较归一化决策间距与存档行序。多个旧代表迁入同一方向时，也按此顺序只保留一个代表。F 质量提高时，代表的目标间距可以增大。
- 存档容量 500，优先保留各方向代表，再按方向内上述排名交错保留其余对。代表仅以单独的行索引维护，用于候选盒与 F 距离排序。
- 首训至少 **8 个存档对**，续训至少 2 个；无训练对数上限、目标距离日程或距离门槛。同一方向的多个对均计入门槛。
- 条件为 **M 维单位参考向量＋真实可行性 0/1**，共 M+1 维；F/I 各自使用当前 Z 下的方向。噪声维数始终为 D，Z 不直接输入网络。上次成功训练的端点与条件快照保持原样，原点更新不重置网络或 Adam。查询使用可行侧条件 1，但生成点仍需真实约束评价。

## 全部固定参数

| 项目 | 参数 |
|---|---|
| 统一运行配置 | N=100，D=30，maxFE=150000；完整对照口径为 runs=5，种子 1–5，10 个进程 worker，每 worker 1 个计算线程 |
| 子代 | P1=50，P2=50，总计 100 FE/代；初始化 200 FE，完整搜索 1498 代 |
| DE | `OperatorDE` 默认 CR=1、F=0.5、proM=1、disM=20；不同父代索引，二元锦标赛 |
| 生成器 | `[z;c]` 共 D+M+1 维，`(D+M+1)→128→D`，sine 激活，线性输出 |
| 噪声 | D 维正态输入，sigma=0.02；F/I 两侧均经第一层可学习权重进入隐藏层 |
| 初始化 | 首层噪声列采用 Glorot 均匀边界 `sqrt(6/(D+M+1+128))`；参考向量列保留 256 倍正态初始化，侧标签列保留 `[0,2*pi)` 均匀初始化。256 不是每层的正弦频率乘数 |
| 判别器 | `(D+M+1)→16→1`，leakyReLU(0.2)，无界标量输出 |
| 可学习参数量 | G 与 D 合计：D=30 时，M=2 为 8783，M=3 为 8927 |
| 训练触发 | 首次 8 个存档对；之后至少 2 个，间隔达到 20 代或全部存档内容变化达到阈值；当前阈值 0.2；无重置 |
| 更新次数 | 首训 G=6000；续训 G=1000；每次 G 对应 C=2 次 |
| 批次 | `2*max(F方向组数,I方向组数)`，两侧各半；方向组均衡抽样，同侧相同端点去重；不按配对总数直接扩大批量 |
| 学习率、Adam | 每次训练事件内指数衰减 0.001→0.000001；β1=0、β2=0.9 |
| C 损失 | WGAN＋GP×10；梯度范数根号稳定项 1e-12 |
| G 损失 | −平均 C 分数＋100×同方向同真实侧最近端点 RMS；根号稳定项 1e-8 |
| 内容变化 | 双向最近移动平均，除以 `max(旧决策距离,1e-3*sqrt(D))`；方向新增/消失、条件集合变化或同一端点的条件变化时，该组记作 1，再对方向取平均 |
| 候选查询 | 500 个，按全部参考方向均分；不能整除时将余数随机分给不同方向，次数相差不超过 1。模型可用后不受当前与上次训练方向交集限制，当前无代表的方向也可查询 |
| 基础筛选 | 两类方向均检查有限值、裁至问题变量边界，并与 P1/P2、全部存档端点及已选候选去重；归一化决策去重距离 >1e-6 |
| 有代表方向 | 全部方向代表的 F/I 两侧端点逐维 min/max 建共同盒，容差 1e-12；其他存档对不扩盒。该请求方向的盒外候选淘汰、不投影；盒内按距离对应 F 从近到远排序，无距 F 硬门槛 |
| 无代表方向 | 不受存档盒子限制；用原判别器按条件 `[单位参考向量,1]` 的分数从高到低排序。输入决策沿用训练的 [-1,1] 归一化；不设分数阈值，有限负分也可入选，不跨方向比较分数 |
| 名额分配 | 随机排列请求方向，每方向至多选 1 个；最优候选与已选点重复时尝试本方向下一候选。两类方向共用原 G 总配额，无盒内/盒外或探索独立名额，不足由 DE 补齐 |
| 存档数值边界 | 决策距离平方 >1e-24；边界容差 1e-12；I 端点支配筛选容差 1e-12 |

## 使用与验证

按PlatEMO通常方式添加依赖后运行；不要递归添加 `Experiments`，避免历史同名函数遮蔽。

```matlab
P = LIRCMOP7_BC('N',100,'D',30,'maxFE',150000,'maxRuntime',Inf);
A = GANCMO('save',0,'outputFcn',@(varargin)[]);
A.Solve(P);
```

根目录 `test.m` 继续作为普通并行启动脚本。算法本身不计算或保存性能指标，不包含 `RecordTrace`、覆盖率诊断或初次训练数据副本。完整验证通过PlatEMO原生 `save=75` 保存种群，在隔离实验中独立复算最终/过程IGD。

局部回归：`addpath('Tests'); test_GANCMO_mainline; test_GANCMO_reference`。检查包括精确FE、独立RNG、历史最小值、端点迁移、配对合法性、质量优先代表、全部对训练、条件变化触发、候选排序/去重，以及不同维度下网络前向与续训。理想点观测由测试临时副本完成，不在生产路径保留诊断分支。

历史原始MAT、报告、冻结执行脚本和压缩源码用于复核，不能视作仍可采用的算法版本；旧报告中的IGD和提速结论只对应各自的冻结源码。
