# GANCMO 唯一主线

当前实现采用 G128/C128、共同噪声标准差1、固定学习率0.001、初训1000/续训200个完整epoch（续训至多1000次G更新）、8方向训练资格，以及公式2配合不回升的动态阈值。G首层参考方向权重的初始化标准差为128。每个被访问的参考方向仅生成一个CGAN子代，直接交由真实评价；参数仅由 `GANCMOSettings.m` 定义，无实验版本开关。

## 算法流程

P1 按约束选择，P2 忽略约束；两者容量均为 N。每代总计 N 个新评价，通常各 N/2 个；预算尾部按剩余 FE 截断。P1 的 CGAN 计划比例为 `0.1+0.8*p`，其中 `p=(FE-初始FE)/(maxFE-初始FE)`。候选不足由 DE 补齐，P2 全部使用 DE。两种群共享 DE 子代；CGAN 子代只参与 P1 选择。CGAN 不调用 GA，不经过 DE 二次加工。

两种群的环境选择均采用 SPEA2：强度适应度加第 `floor(sqrt(候选数))` 近邻密度，超额非支配解按排序后的邻距逐个删去最拥挤者。密度和截断均以 `pdist2` 计算原始目标空间的欧氏距离，避免平方范数相减使极近点距离失真；不增加目标归一化、参考方向配额或参数。2026-10-15 的数值回归及历史保存种群检查见[检查报告](../../../Experiments/GANCMO_SelectionDistance_20261015/REPORT.md)。

初始化后，以 P1/P2 全部目标值的逐列最小值建立 Z。每代先用当前存档决定是否训练和生成，评价全部子代后更新 Z，再选择两个种群，并以选择前的完整已评价并集更新存档。Z 取历史最小值，包含不可行、未被种群或存档保留的已评价解。批量取最小值与逐个子代更新等价；本代训练和查询共用代初的原点，存档更新采用评价后的原点。生成只使用请求参考方向和可行侧标签，不再使用存档代表筛选候选。训练、查询和 DE 使用独立随机流。

运行时前向计算使用 `fullyconnect`、`sin`、`leakyrelu`；自动微分只跟踪本次更新所需变量：Critic步骤跟踪Critic参数和插值决策，G步骤只跟踪G参数；其余输入仍参与原有前向和损失计算，但无需计算它们的梯度。`dlnetwork` 用于初始化与保存网络结构；每次训练事件内复用参数数组，仅缓存G/Critic前向算子的执行图，损失及求梯度顺序保持原样；执行自动微分和 MATLAB `adamupdate`，事件结束后写回网络与优化器状态。G 的直接前向与网络图均对 `[z;c]` 执行全连接、sine、全连接运算。F/I 两侧共享同一输入路径，无独立噪声支路、固定噪声增益或输出端噪声相加。

## 存档与条件

- 参考方向由 `UniformPoint(N,M)` 创建一次并保持固定，使用返回的方向数，不修改种群 N。N=100 时，M=2 得到 100 个方向，M=3 为 91 个。
- `Scale.minimum=Z`、`Scale.span=1`，目标只作 `f-Z` 平移，不压缩到 [0,1]。每次存档更新都用当前 Z 重新分配全部新旧 F/I 端点的最小夹角方向，配对 `ref` 取 F 方向。零向量沿用确定性归属规则。方向邻域按 W 的夹角取最近 5 个，含自身，保持固定。
- 新旧端点合并后检查有限值、决策边界并去重：F 属于合并可行池的非支配前沿，I 不被该前沿支配。初始化及后续更新使用同一规则，无 10% FE 切换。
- 历史存档只提供端点；全部配对按当前 Z 重建。每个合格 F 在上述邻域内寻找目标距离最近的合法 I；同距时按 I 决策向量的字典序选择，找不到则不建对。每个 F 最多形成一对，同一个 I 可以被多个 F 使用。
- 同一方向的 F 在本次更新内复用合法 I 索引；该索引随当前 Z 和端点池重新建立，不跨代缓存，也不改变逐 F 的决策间距检查及最近 I 选择。
- 每对只保存 `ref`、`xf`、`yf`、`xi`、`yi`，配对间距按需计算。全部保留的合法对都用于训练，不保存编号、活动状态或转移标记。P1 归属、旧配对关系与旧代表身份不参与保留判断。
- 每方向优先最小化 `max((yf-Z)./(W(ref,:)+1e-12))`，再比较原始目标空间 F/I 欧氏距离；两项相同时比较归一化决策间距，最后按 F 决策向量的字典序确定顺序。该排序用于每方向的存档容量保留，子代查询不使用代表对。
- 每方向硬性最多保留 **5 对**，不足时保留实际数量，空余名额不转移。实际方向数为 R 时，总容量自然不超过 **5R**，不另设全局截断：N=100 时双目标最多500对、三目标91个方向最多455对。不为凑满容量放宽资格或邻域。
- 首训和续训均至少 **8 个有效 F 方向**。有效方向指当前 Z 下至少有1个合法存档对的 F 方向，同一方向的多个对只计一次。方向数只控制训练门槛；训练使用全部保留对，不另设训练对数上限、目标距离日程或距离门槛。超过阈值时方向不足则跳过训练并关闭生成，已有模型及Adam保留；未超阈值时不因方向数变化切换使用权限。
- 条件为 **M 维单位参考向量＋真实可行性 0/1**，共 M+1 维；F/I 各自使用当前 Z 下的方向。噪声维数始终为 D，Z 不直接输入网络。上次成功训练的端点与条件快照保持原样，原点更新不重置网络或 Adam。查询使用可行侧条件 1，但生成点仍需真实约束评价。

## 存档变化、动态阈值与使用权限

存档每代重建。将F/I端点按变量上下界归一化到[0,1]，每对取决策空间中点；当前中点集对上次成功训练中点集的平均最近邻距离为公式2：

$$
\Delta_t=\frac{1}{|\mathcal T_t|}\sum_{(F,I)\in\mathcal T_t}\min_{(F^*,I^*)\in\mathcal T^*}\left\|\frac{F+I}{2}-\frac{F^*+I^*}{2}\right\|_2.
$$

该量按当前配对等权，不按参考方向等权。它比较上次成功训练快照，不是与上一代比较；也不同于目标空间的性能IGD。

实现中先求成对平方距离的最近值，再对最近值开方，减少开方次数。r 的 RMS 仍保留各最近距离先开方再平方的舍入顺序；距离定义和触发条件不变。

阈值的辅助量d另行计算当前中点到**上一有效观测中点集**的平均最近距离。r是当前去重中点集内最近邻距离的RMS（不是到中心的半径），R是固定W的实际行数。以首训中点集确定r0，初值s=theta=sqrt(R)*r0；k从首训不同中点数开始，只在正局部移动d>0时加1。其更新为：

$$
s_k=s_{k-1}+\frac{\max(\sqrt{r_t d_t},\sqrt R\,d_t)-s_{k-1}}{\sqrt{k}},\qquad
\theta_t=\min(\theta_{t-1},s_k),\qquad |\Delta_t|>\theta_t.
$$

s可回升，实际theta永不回升。阈值没有显式D衰减项，也不使用FE/maxFE或目标训练间隔；所有距离同比例缩放时，分数和阈值同比例变化，触发不变。真实改变D仍会改变搜索路径与训练资格。根式步长及尺度合成是明确的启发式设计选择，不宣称理论唯一性。

1. 无模型时逐代等待原首训资格；首次成功训练的快照用于随后首次检测时初始化状态。重合中点无法定义间距时使用不同F/I端点的最近邻尺度及其点数，不增加训练资格条件。
2. 每次有限公式2分数（包括0）都更新上一有效观测中点集。局部移动d>0时更新尺度；d=0只暂停尺度学习，仍执行原公式2的严格绝对值比较，没有独立Delta>0门槛。当前少于两个不同中点时保留s/theta；空或非有限分数暂停全部检测状态及权限。
3. 成功训练不重置k、s或theta；方向资格不足也不暂停可计算的观测。未超阈值保持当前CGAN权限；超阈值先关闭，仅在G更新计数真正增加后开启。
4. 只有成功训练更换公式2比较快照。训练保持完整epoch及原非有限回退，网络、Adam、计数和成功快照的回退规则不变。停用时保留模型和预留查询随机流消费，CGAN名额由DE补足。

没有固定检查周期、冷却期或间隔上下限。10–20代仅用于实验评价；即使阈值下降，资格不足或长期无变化仍可能形成长等待。使用权限也不保证全部查询方向都有训练覆盖。

## 全部固定参数

| 项目 | 参数 |
|---|---|
| 常用基准配置 | N=100，D=30，maxFE=150000；候选数量对照为LIRCMOP7_BC/8_BC、runs=5、种子1–5；历史实验保留原口径 |
| 子代 | P1=50，P2=50，总计 100 FE/代；初始化 200 FE，完整搜索 1498 代 |
| DE | `OperatorDE` 默认 CR=1、F=0.5、proM=1、disM=20；不同父代索引，二元锦标赛 |
| 存档容量 | `pairsPerDirection=5`；每方向最多5对，总数自然不超过5R，空余名额不转移 |
| 生成器 | `[z;c]` 共 D+M+1 维，`(D+M+1)→128→D`，sine 激活，线性输出 |
| 噪声 | D 维正态输入，训练和生成共用sigma=1；F/I 两侧均经第一层可学习权重进入隐藏层 |
| 初始化 | 首层噪声列采用 Glorot 均匀边界 `sqrt(6/(D+M+1+128))`；参考向量列为 `128*randn`，即均值0、标准差128的正态初始化，无固定上下界；侧标签列为 `[0,2*pi)` 均匀初始化。上述连接权重参与训练，sin自身无可训练参数 |
| 判别器 | `(D+M+1)→128→1`，leakyReLU(0.2)，无界标量输出 |
| 可学习参数量 | G 与 C 合计：D=30 时，M=2 为 12703，M=3 为 12959 |
| 训练检查/使用 | 公式2的`abs(Delta)>theta`；theta由局部移动与中点间距形成尺度、平滑后取历史下界，无D时钟。有限分数包括0均参与检测；首训/续训共用`minimumDirections=8`；未超阈值保持权限，超阈未成功则关闭，成功后开启 |
| 训练轮数 | 初训1000 epoch；续训目标200 epoch，同时最多1000个G更新，只执行完整epoch；每批G=1、C=2 |
| 批次 | 同侧相同端点去重，F/I分别无放回打乱，每轮每个端点调度一次，保留尾批；名义批量B=`2*max(F方向组数,I方向组数)`，每轮K=`min(ceil((nF+nI)/B),nF,nI)`批，分别均分F/I端点；每批两侧平均损失各占一半 |
| 学习率、Adam | G和C的初训、续训均固定0.001；β1=0、β2=0.9 |
| C 损失 | WGAN＋GP×10；梯度范数根号稳定项 1e-12 |
| G 损失 | −平均 C 分数＋100×同方向同真实侧最近端点 RMS；根号稳定项 1e-8 |
| 子代生成 | 每个实际参考方向仅预留一个候选及一行D维噪声，条件为 `[单位参考向量,1]`。按剩余G名额分批访问方向；N=100时，M=2有100个方向，M=3有91个方向 |
| 评价前处理 | 仅检查有限值并裁至问题变量边界；不做共同盒、候选去重、F距离排序或Critic评分，不区分有无代表的方向。同值子代也可直接评价 |
| 名额分配 | 随机访问全部请求方向，每方向至多直接使用一个候选，共享原G总配额；名额用满即停止。非有限方向继续由后续方向递补，全部方向尝试后仍不足才由DE补齐；不增加每代真实评价预算 |
| 存档数值边界 | 决策距离平方 >1e-24；边界容差 1e-12；I 端点支配筛选容差 1e-12 |

按需推理每批访问 `max(8,剩余G名额)` 个方向，末批可更少。每方向仅有一个候选，不再生成多个后排序选择。极小G批次通过重复输入补至 `min(16,实际方向数)` 行，补行输出丢弃，不形成额外候选或真实评价。预留噪声与方向访问顺序沿用已验证的“1个直接用”实验；停用时保留相同查询随机流消费，不再保留500候选配置或Critic近同分回退。

## 使用与验证

按PlatEMO通常方式添加依赖后运行；不要递归添加 `Experiments`，避免历史同名函数遮蔽。

```matlab
P = LIRCMOP7_BC('N',100,'D',30,'maxFE',150000,'maxRuntime',Inf);
A = GANCMO('save',0,'outputFcn',@(varargin)[]);
A.Solve(P);
```

根目录 `test.m` 继续作为普通并行启动脚本。算法本身不计算或保存性能指标，不包含 `RecordTrace`、覆盖率诊断或初次训练数据副本。检测器仅保留后续更新必需的五个状态字段；配对和代表唯一性由存档构造保证，在回归中检查，不在每代重复排序验证。完整验证通过PlatEMO原生 `save=75` 保存种群，在隔离实验中独立复算最终/过程IGD。

局部回归：`addpath('Tests'); test_GANCMO_selection; test_GANCMO_mainline; test_GANCMO_reference; test_GANCMO_training_window`。检查包括距离缩放/复制坐标的触发不变性、重合/单中点退化输入，以及1000/200默认预算、完整epoch端点覆盖与尾批、F/I各半损失权重、续训G更新上限、固定学习率拆分训练的权重/Adam/RNG一致性，以及网络联合输入输出。训练权限回归覆盖公式2原义、严格等号不触发、零分数检测、无效观测暂停、资格不足/训练回退关闭、未超阈权限保持、成功重开与快照回退、DE补足及尾部FE。另核对存档配对/代表/容量、每方向单候选、同值解直接使用、共享配额及查询随机流、历史理想点、环境选择近点数值稳定性和独立随机流；观测仅放测试临时副本，不在生产路径保留诊断分支。

历史采用及实验结果保留在各自 `Experiments` 目录中，不作为可切换的生产实现。本次清理与等价优化的范围、测试和计时见 [验证报告](../../../Experiments/GANCMO_CleanupSpeed_20261019/REPORT.md)。局部计时不能外推为整次搜索提速，完整 IGD 结论以实际完成的核验为准。
