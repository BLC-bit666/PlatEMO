# 连续工程问题的总体二元约束版本

| 类 | 变量顺序 | 目标（均最小化） | 内部工程不等式 |
|---|---|---|---:|
| `WeldedBeam_BC < PROBLEM` | `[h,l,t,b]` | 制造成本、末端挠度 | 7 |
| `FiveStageCantileverBeam_BC < PROBLEM` | `[b1,…,b5,h1,…,h5]` | 材料体积、末端挠度 | 11 |
| `TubularColumn_BC < PROBLEM` | `[d,t]` | 制造成本、轴向压缩量 | 2 |
| `PressureVessel_BC < PROBLEM` | `[Ts,Th,R,L]` | 制造成本、容量差额 `Vmax-V` | 4 |
| `ReinforcedConcreteBeam_BC < PROBLEM` | `[As,h,b]` | PDF 成本指标、钢筋截面积 | 2 |
| `ThreeBarTruss_BC < PROBLEM` | `[A1,A2]` | 材料体积、归一化节点位移 | 3（仅第一条独立） |

各类均固定 `M=2`，按上表顺序分别固定 `D=4、10、2、4、3、2`，所有 `encoding=1`。构造时传入其他 M/D 会被 `Setting` 恢复为该工程模型的固定维数。它们是数值工程约束的二元化版本，不是天然二元约束问题。

当前新增的是钢筋混凝土梁和三杆桁架。按用户要求，五级悬臂梁、管柱和压力容器不再纳入本轮新实验；保留其历史实现与结果。新入口只验证及运行本轮两个问题。

## PlatEMO 调用关系

沿用父类 `PROBLEM` 的构造、`Initialization`、`Evaluation`、`CalDec` 和 `GetPF`。实际求值链为：

`Initialization/变异算子 → PROBLEM.Evaluation → CalDec → CalObj + CalCon → SOLUTION → FE 增加`。

- `CalDec` 只修复变量盒越界，不修复工程不可行性；连续尺寸不取整。
- `CalObj(X)` 返回 N×2 真实解析模型目标，包括不可行设计；不加罚值、不删行、不插补。
- `CalCon(X)` 返回 N×1 的 `double`：全部 `g_i/scale_i≤1e-12` 为 0，任一超过该阈值为 1。不返回违反幅度或违规项数。
- 采用固定的归一化数值容差 `1e-12`，处理打印坐标舍入及浮点运算造成的极小正残差。所有算法使用同一个判定，不随样本、迭代或算法调整。
- `CalObj/CalCon` 本身不增加 FE；`Evaluation(X,Add)` 由父类传递附加数据并按实际解数增加 FE。
- 焊接梁与五级悬臂梁的 `CalCon` 调用同一个 `CalObj` 获取挠度；压力容器的目标和约束共用私有 `Capacity` 方法，确保同一物理量使用相同算术。
- 直接调用 `CalObj/CalCon` 时应传入声明变量盒内的 N×D 数组；边界修复发生在标准 `Evaluation` 调用中。

### 数值容差

保留 PDF 原始残差表达式，仅将最后的二元判定改为 `double(any(RawCon./scale>1e-12,2))`。各尺度固定为对应工程限值；焊接梁 `h-b` 使用两变量共同的上界 2。

| 问题 | 按代码顺序排列的约束 | 固定尺度 |
|---|---|---|
| 焊接梁 | 剪应力、正应力、`h-b`、成本限制、最小焊缝厚度、挠度、屈曲载荷 | `[13600,30000,2,5,0.125,0.25,6000]` |
| 五级梁 | 五项应力、五项高宽比、挠度 | `[14000×5,20×5,2.7]`（前两项各重复五次） |
| 管柱 | 屈服、屈曲，PDF 原残差已无量纲 | `[1,1]` |
| 压力容器 | 筒体厚度、封头厚度、最小容量、最大长度 | `[1,1,1296000,240]` |
| 钢筋混凝土梁 | 深宽比、承载指标 | `[4,180]` |
| 三杆桁架 | 三项应力 | `[2,2,2]` |

这会接受宽度为 `scale_i*1e-12` 的极小边界带，并非数学上完全不变的严格零阈值。例如五级梁应力的允许数值残差为 `1.4e-8`，足以覆盖 PDF 坐标约 `1e-11` 的舍入残差。目标函数、变量边界、工程常数以及 PDF 的挠度系数均不因此改变；明显超限的点仍返回 1。

### 焊接梁

采用 PDF 求解代码的边界 `[0.1,0.1,0.1,0.1]` 至 `[2,10,10,2]`，完整保留七项不等式。原成本目标为：

`f1=1.10471 h²l+0.04811 tb(14+l)`。

将原来已经计算的 `δ=4PL³/(Et³b)` 同时作为第二目标，仍保留 `δ≤0.25` 约束。常数 `P=6000,L=14,E=3e7,G=1.2e7`。

屈曲载荷取 PDF **代码及数值结果对应的表达式**：

`Pc=4.013 E sqrt(t²b⁶/36)/L² × (1-t/(2L) sqrt(E/(4G)))`。

不采用排版式中额外的 P，也不采用当前本地 `RWMOP4` 的 `t²+b⁶`。本题的边界、约束数和公式版本均不同于该文件以及 pymoo 的四约束版本，不混用其参考前沿。

### 五级悬臂梁

编号从固定端到受载端。五段长度均为 100，`P=50000,E=2e7,σmax=14000,δmax=2.7`。变量边界：

```matlab
lower = [1,2.4,2.4,1,1,30,45,45,30,30];
upper = [5,3.1,3.1,5,5,60,60,60,60,60];
```

原体积 `100*sum(b.*h)` 为第一目标，将 PDF 原式的末端挠度同时作为第二目标，保留挠度上限及五项应力、五项高宽比限制。

**当前版本严格采用 PDF 求解代码的系数：**

`δ=P*100³/(3E) × Σ [244,148,76,28,4]_i/(bi hi³)`。

此次撤回了之前去掉 `/3` 的公式校正，以符合“除增加第二目标和约束二元化外，按 PDF 代码复现”的要求。对 PDF 给出的设计，体积为 `61914.78900888449`，挠度为 `0.9392849999721066`，与其数值结果一致。还通过各段应力与高宽比同时取等号的解析解核对了 PDF 的原单目标最小体积。

PDF 打印的设计坐标位数有限，代入时会出现约 `10^-11` 的应力正残差；这不等于挠度超限。固定归一化容差可吸收这一级别的误差，无需修改该设计坐标。两个问题的 PDF 参考设计现在均返回 `C=0`，目标值保持原样。

标准 Euler–Bernoulli 柔度积分得到的挠度仍是 PDF 式的三倍；这个源模型差异单独记录，当前实现不自行修正它。验证目标是与 PDF 代码一致，不宣称源公式已经完成物理校正。

### 管柱

`x=[d,t]` 为平均直径和壁厚，边界 `[2,0.2]` 至 `[14,0.8]`，单位 cm。保留 PDF 常数 `P=2500 kgf、L=250 cm、E=0.85e6 kgf/cm²、σ=500 kgf/cm²`。

```text
f1 = 9.8 d t + 2 d                       （PDF 原成本）
f2 = PL/(Eπdt)                           （新增：名义弹性轴向压缩量）
g1 = P/(πdtσ)-1
g2 = 8PL²/[π³Edt(d²+t²)]-1
```

PDF 给定点 `[5.45115623425486,0.291965477143678]` 的成本为 `26.4994968915155`，新增压缩量约为 `0.1470588235294116 cm`，标签为 0。全变量盒内 `d>t>0`，分母不会为零；不可行设计仍返回名义弹性响应，但不能把它解释为失稳后的实际位移。

### 压力容器

`x=[Ts,Th,R,L]` 为筒体厚度、封头厚度、内半径和筒体长度。边界 `[0.0625,0.0625,10,10]` 至 `[6.1875,6.1875,200,200]`。严格采用 PDF 第 4 页代码中的**连续厚度版本**，不按 `0.0625` 的倍数取整。

```text
f1 = 0.6224 Ts R L + 1.7781 Th R² + 3.1661 Ts² L + 19.84 Ts² R
V  = πR²L + (4/3)πR³
f2 = Vmax - V
g  = [0.0193R-Ts, 0.00954R-Th, 1296000-V, L-240]
Vmax = π×200²×200 + (4/3)π×200³
```

第二目标是新增的容量目标：`Vmax` 由固定变量上界给出，最小化 `Vmax-V` 与最大化 V 有相同的优劣排序和 Pareto 集。它相对筛选报告中的 `-V` 只增加一个固定常数。采用该形式是因为本地原生 `HV.m` 用 `min(当前可行前沿最小值,0)` 作归一化下界；负容积会让下界随种群变化，非负的容量差额让所有运行统一使用零下界。目标平移不改变 Pareto 支配关系，但依赖目标绝对位置的算法数值轨迹可能改变，因此实现版本应统一记录，不能把两种表达的历史实验混用。

PDF 给定点 `[0.778168641375371,0.384649162628201,40.3196187241089,199.999999999858]` 的成本为 `5885.33277361788`，容积约为 `1296000`，标签为 0。容量差额仍为真实解析模型量，不是不可行罚值。四条不等式全部保留；其中 `L≤240` 已被盒上界 `L≤200` 蕴含，不声称其构成独立难度。

管柱和压力容器均保留原单目标和原可行域（仅有统一浮点容差），增加有工程含义的第二目标。目标和工程约束在整个声明变量盒内均有有限值。

### 钢筋混凝土梁（2026-11-19 新增）

来源为同一 PDF 第 19–21 页，§34.2.12。固定变量 `x=[As,h,b]`，边界 `[1,28,5]` 至 `[28,40,10]`。`As` 为连续钢筋面积，`h` 为截面深度，`b` 为宽度。PDF 正文把后两者的名字写反，实施只按公式澄清名称，不交换数值坐标或边界。

```text
f1 = 2.9 As + 0.6 h b                 （PDF 原成本指标）
f2 = As                               （新增：固定梁长下的钢筋用量指标）
g1 = h/b - 4
g2 = 180 + 7.375 As²/b - As h
```

`b>=5`，故整个盒内目标和约束均有限。第二目标不使用违反度。PDF 原样坐标 `[10.8193202576482,28.0254713275768,7.0063678318942]` 的成本为 `149.190085217104`；可行设计 `[5,40,10]` 的成本为 `254.5`、钢筋面积为 `5`，体现成本与钢材用量的取舍。PDF 材料报价说明与代数成本系数尚未建立一致的单位换算，因此只称该式为 PDF 成本指标。

### 三杆桁架（2026-11-19 新增）

来源为同一 PDF 第 8–9 页，§34.2.5。两根斜杆面积同为 `A1`，中间竖杆面积为 `A2`，`H=100,P=2,σallow=2`。保留 PDF 原体积和三条应力不等式，新增 45° 载荷下的归一化位移：

```text
f1 = 100(2√2 A1 + A2)
f2 = sqrt(1/A1² + 1/(A1+√2 A2)²)
s1 = 2(√2 A1+A2)/(√2 A1²+2 A1 A2)
s2 = 2 A2/(√2 A1²+2 A1 A2)
s3 = 2/(A1+√2 A2)
g  = [s1-2,s2-2,s3-2]
```

真实名义线弹性位移模长为 `(PH/E)f2`。PDF 没有指定弹性模量，所以不编造 E，也不把 `f2` 标成 mm。独立验证通过组装二维节点刚度矩阵求位移及杆应力，核对全部公式。

变量盒为 `A1∈[0.1,1], A2∈[0,1]`。相对 PDF 唯一的边界变化是将 `A1` 下界从 0 提至 0.1，以去除零截面奇点；`A2=0` 时两根斜杆仍构成稳定体系，保留该边界。由于 `s1` 随 `A2` 增大而下降，且 `A2<=1`，任意原可行解都需满足 `√2 A1²+(2-√2)A1-1>=0`，即 `A1>=0.6589186225978911`。因此这个域调整不删除原可行设计，不能称为原变量盒完全不变。

PDF 原样坐标 `[0.788675140591979,0.408248273501316]` 的体积为 `263.895843376468`。三项约束全部保留；`s1>=s2,s3`，实际只有第一项独立，不把三项都算成独立难度。不可行设计仍计算有限的名义弹性响应，不是实际破坏后的位移。

## 指标和参考数据

没有把未验证的近似前沿当作真实 Pareto 前沿。继承的 `GetPF()` 返回空数组。

`GetOptimum` 提供固定、保守的 HV 归一化上界（不是 Pareto 点）：

- 焊接梁 `[67.2812,0.25]`：成本由整个变量盒的上界得到，挠度由可行性上限得到。
- 五级梁 `[127200,2.7]`：体积由整个变量盒的上界得到，挠度由可行性上限得到。
- 管柱 `[137.76,500*250/0.85e6]`：成本取盒上界，压缩量由屈服限值推出。
- 压力容器 `[f1(upper),Vmax-1296000]`：成本取盒上界，容量差额由最小容量约束推出。
- 钢筋混凝土梁 `[321.2,28]`：两目标均取盒上界。
- 三杆桁架 `[100(2√2+1),2]`：体积取盒上界；`s1=1/A1+1/(A1+√2 A2)<=2` 可界定相应二范数位移目标不超过 2。

原生 `HV.m` 会再乘 1.1 形成其归一化参考盒，足以覆盖数值容差产生的极小边界带；无需额外增加一遍裕量。上界不代表真实 nadir。`CalMetric('HV',Population)` 使用它们；其他指标收到空参考集，`IGD/GD` 返回 NaN，`Feasible_rate` 等不依赖参考前沿的指标正常工作。没有可行解时沿用 PlatEMO 原生指标行为，不补成 0。
