# 已确定的项目语义，不要擅自反向修改

1. LIR-CMOP_BC 和 DAS-CMOP_BC 中，每个候选解只公开一个聚合二值约束值：可行为 `0`，不可行为 `1`。不要恢复成逐约束二值列，也不要反推隐藏原始约束。
2. 每个具体问题类应有独立 `CalCon`，不要修改基类 `PROBLEM.CalCon`。单个决策向量调用返回一个标量 `0/1`；N 个个体批量输入时，PlatEMO 以 `N×1` 保存 N 个独立标量，这不是 N 个约束标签。
3. EADMM 原文可以利用逐约束二值信号，而本项目目标问题只公开一个聚合信号。这是问题信息边界和 EADMM 的适用弱点，不能新增机制或泄露隐藏约束来弥补。
4. EADMM 局部 GA 内部只查询二值约束标签和距离，这些查询不计入 PlatEMO 外层多目标 FE；每个 GA 最终得到的 `xcheck` 经一次 `Problem.Evaluation`，该次计入 FE。
5. EADMM 正式实验人口规模按补充材料核对：目标数 `m=2/3` 时 `N=100`，`m=5/10` 时 `N=150`。MOEA/D 权重生成不得悄悄改变实际人口规模。当前使用 MUD 精确生成 N 个权重，需要判断其是否是满足已知要求的必要推断，并明确作者未公开原始权重生成方式。
6. NA-EMT 初始 `N1=1000` 个训练样本属于真实问题评价，必须计入 `200000` FE；两个初始种群与所有后代同样计入。
7. NA-EMT 在线更新网络时从现有网络权重继续训练，不应每次重新创建网络冷启动。论文若未明示，要标为对“更新模型参数”和连续在线训练语义的最小推断。
8. NA-EMT CDPPV 高置信组统一采用 `Value>=epsilon`，消除恰好等于阈值时的关系空洞。

如果你认为上述某条与论文或 PlatEMO 存在冲突，不要直接忽略它。请分别说明：论文原始算法要求、PlatEMO 接口要求、本项目目标问题语义、冲突后果和可选处理。

# 如何衡量“差距有多大”

不要只给主观结论。分别统计：

- 论文明确模块总数；
- `一致`、`部分一致`、`不一致`、`必要推断`、`无法确认`的数量；
- P0/P1/P2/P3 问题数量；
- 是否存在会改变算法身份、选择压力、信息使用、FE 口径或实验公平性的关键偏差；
- 在修复前，当前实现应归类为：`高度忠实`、`基本忠实但有关键偏差`、`部分复现`、`不能称为论文复现`；
- 给出上述归类的证据和置信度，不制造没有依据的精确百分比。
