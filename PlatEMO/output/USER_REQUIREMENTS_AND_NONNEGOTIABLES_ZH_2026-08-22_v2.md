# 用户原则与不可变决策（clean v2）

## 本次 GPT 任务

严格依据两篇论文、EADMM 正式补充材料和 PlatEMO 官方规范，审查现有 EADMM、NA-EMT 代码：

1. 现有实现与论文真实描述差距有多大；
2. 全部不一致、遗漏、错误推断与无法确认项是什么；
3. 如何在现有实现基础上做最小修改，最大程度达到一比一复现。

不是重新实现，不是改进算法，不是性能增强，也不是只找几个示例问题。

## 证据边界

1. 算法事实只来自正式论文、作者/出版社正式补充材料或勘误。
2. 平台事实来自 BIMK 官方 PlatEMO：https://github.com/BIMK/PlatEMO
3. 不引用包外算法实现填补论文空白。
4. 代码注释和 `REPRODUCTION_NOTES.md` 都是待核查主张，不是真值。
5. 论文未说明但程序必须选择的细节，才采用 PlatEMO 既有设施或领域常见设置；逐项记录理由、影响、置信度。
6. 官方材料没有公开的信息必须保留为“无法确认”或“必要推断”，不能伪称绝对一比一。

## 复现底线

1. 严格按论文思想、步骤、公式、参数与实验口径复现，禁止自由发挥。
2. 非运行所必需，不增加论文没有的机制、模块、参数、缓存、启发式或修复算子。
3. 优先复用 PlatEMO 基类、公共算子和约定。
4. 在现有实现上做最小局部修复，避免无关重构。
5. 必须穷尽两个算法的全部偏差，不能发现一个问题后停止。
6. 每项结论都要对应 PDF 页码/公式/算法/表格和代码文件/函数/行号。
7. 区分算法思想偏差、PlatEMO 集成错误、实验设置偏差、目标问题信息限制。
8. 性能慢先诊断根因；不得为提速改变论文语义、随机过程、选择压力或评价口径。

## 已确认、不得反向修改的决策

1. LIR-CMOP_BC、DAS-CMOP_BC 每个候选解只公开一个聚合二值约束值：可行 `0`、不可行 `1`。禁止恢复逐约束二值列，禁止反推隐藏约束。
2. 每个具体问题类有独立 `CalCon`；不修改基类 `PROBLEM.CalCon`。单个决策向量返回标量 `0/1`；批量 N 个解的 `N×1` 只是 N 个独立标量的 PlatEMO 存储形式。
3. EADMM 原文可以利用逐约束信号，而目标问题只有一个聚合信号。这是信息边界与算法适用弱点，不通过新增机制弥补。
4. EADMM 局部 GA 内部二值标签查询不计 PlatEMO 外层多目标 FE；每个最终 `xcheck` 的一次 `Problem.Evaluation` 计 FE。
5. EADMM 正式人口规模按补充材料核对：`m=2/3` 时 `N=100`，`m=5/10` 时 `N=150`。MOEA/D 不得因权重生成悄悄改变实际 N；MUD 属于作者未公开权重生成方式后的必要推断。
6. NA-EMT 初始 `N1=1000` 个训练样本计入 `200000` FE；两个初始种群和所有后代同样计入。
7. NA-EMT 在线更新沿用现有网络权重继续训练，不每次重建网络冷启动；标注为论文未明示后的最小推断。
8. NA-EMT CDPPV 高置信组统一为 `Value>=epsilon`。
