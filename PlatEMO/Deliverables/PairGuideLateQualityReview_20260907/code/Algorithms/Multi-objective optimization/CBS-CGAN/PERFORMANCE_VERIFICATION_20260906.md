## 100000 FE 长程验证与容量影响

提速后的固定存档版完成 LIRCMOP7_BC / cgan / seed=1 / N=100 / 默认 D=30 / 100000 FE：

- 搜索墙钟 **416.0145 秒（6.93 分钟）**；存档维护 **13.4508 秒（3.23%）**；训练 340.3881 秒。
- 首次满额在 FE=3800，此后所有已完成代均为 **500 对**；激活最终 100 对；竞争输入最大 **1400 点**。
- 后半程每 10000 FE 的存档耗时约 1.1–1.2 秒，没有随代数增长。
- 完整 FE=100000；实际 CalObj 行次=200000、CalCon 行次=100000，包含原问题的嵌套目标调用，无额外搜索评价。
